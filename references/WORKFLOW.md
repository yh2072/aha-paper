# aha-paper 默认互动视频工作流

这是所有论文项目共用的生成与交付规则，不是单个示例的定制。

1. 从用户 PDF 提取正文与真实主图，过滤标题横幅等非插图。
2. 默认采用深度科普文章人格（`deep_script.py`）：约3000–3600字、10–12章，完整覆盖引言、研究问题、样本与实验设计、对照与指标、关键方法、真实图表、定量结果、局限、应用边界与结论。拒绝娱乐化标题与凑字数。随后对照原文和真实图片独立核对事实，区分相关与机制、百分比与百分点，删除未验证建议，避免猜测图号。每章保留真实PDF页码来源与原图讲解。
3. 普通章节由 Pi + OpenRouter 编写可确定性重绘的 Canvas 动画。
4. 为适合的章节生成小游戏；游戏证据必须能在对应旁白中逐字找到。
5. Edge TTS 整段合成场景旁白，用真实词时间戳对齐每句。
6. 讲图默认使用共享 `anim.py` 的奶油白/鼠尾草绿光标：抗锯齿箭头、柔和阴影、
   淡紫位置尾迹、轻微呼吸环。小范围悬浮，按句子在相关子图间平滑移动。
   普通循环光标与逐句引导光标使用同一绘制函数。
7. 默认构建实时 interactive explainer：只合成连续旁白，按真实配音时长建立大纲与逐句光标时间表。代码页在浏览器按旁白时间实时重绘，原图与光标由 Canvas 实时绘制，不生成逐帧视频。MP4 只在用户主动选择时渲染。
8. 播放器的游戏面板必须是 `.video-shell` 的后代，以绝对定位覆盖在视频上。
   打开时暂停并弱化画面；答题、重试、查看依据、关闭、回到故事都在浮层内完成。
   手机尺寸允许浮层内部滚动，不应撑破视频边界。
9. 全屏操作以视频容器为目标，确保游戏与视频一起进入全屏。
10. 离线互动包直接使用同一 `web/watch.html`、`watch.css`、`watch.js` 模板。
    不维护单独的示例版交互实现。默认网页实时绘制光标、代码场景与逐句字幕，承载大纲和小游戏；可选 MP4 内烘焙光标。

默认模板：`web/watch.*`；光标渲染：`app/pipeline/anim.py`；章节/导出：
`app/pipeline/interactive.py`；编排：`app/jobs.py`。

旧 MP4 中的光标需要重新渲染后更新；新生成和重新渲染的作品自动使用新版光标。
已下载的独立互动包是静态快照，重新导出即可获取新版浮层。

播放器和离线互动包均应展示每章来源，离线包附原论文PDF，不能导出无法追溯数据和图片的“孤立视频”。
